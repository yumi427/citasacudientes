AWS 100% SERVERLESS ARCHITECTURE

Plataforma Móvil CitasAcudientes

Sistema institucional de agendamiento móvil para acudientes y docentes. Arquitectura orientada a eventos con alta disponibilidad, costo cero en reposo y escalabilidad automática.

📱 1. Clientes Móviles
👨‍👩‍👦
Celular Acudiente
PWA Mobile Web
Consulta disponibilidad docente, solicita citas, recibe confirmaciones y cancela citas.
HTTPS / JSON
👨‍🏫
Celular Docente
PWA Mobile Web
Configura franjas de atención, acepta/rechaza solicitudes y registra compromisos escolares.
HTTPS / JSON
⚡ 2. Frontend & Edge
CF
Amazon CloudFront
CDN Global & SSL
Distribución con baja latencia para celulares, compresión gzip/brotli y protección DDoS con AWS Shield.
Edge Caching / OAC
S3
Amazon S3 Bucket
Static Web Hosting
Aloja los artefactos compilados del cliente móvil (SPA/PWA: index.html, JS, CSS, assets). Sin acceso público directo.
Origin Access Control
🚪 3. API & Enrutamiento
API
Amazon API Gateway
HTTP / REST API
Punto de entrada único. Maneja validación de esquemas JSON, CORS para móviles, rate-limiting y throttling.
JWT Authorizer / Lambda Proxy
⚙️ 4. Lógica (AWS Lambda)
λ
Disponibilidad Fn
AWS Lambda
Gestión de horarios de atención del docente por materia y jornada.
GET, POST /disponibilidad
λ
Agendar Cita Fn
AWS Lambda
Reserva transaccional con bloqueo atómico para evitar solapamiento de citas.
POST /citas (TransactWrite)
λ
Gestión Citas Fn
AWS Lambda
Listado por usuario, cancelación, confirmación y registro de compromisos.
GET, PATCH /citas/{id}
🗄️ 5. Base de Datos
DB
Amazon DynamoDB
NoSQL Single-Table
Almacenamiento clave-valor de latencia menor a 10ms. Bloqueo transaccional ACID contra doble reserva.
TransactWriteItems / GSI
⚡
DynamoDB Streams
Event-Driven Stream
Captura cambios de estado (cita solicitada, cancelada) para disparar notificaciones en tiempo real.
Streams → Notificaciones

Principio de menor privilegio: Roles de ejecución dedicados por función Lambda. Acceso a DynamoDB restringido por clave y políticas OAC estrictas para S3.
